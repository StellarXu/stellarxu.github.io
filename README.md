# Xu, Chen / astroR2 - Homepage

纯静态网站, 直接改 html 即可, 可直接部署到 GitHub Pages。

## 文件说明
- index.html     首页 (大图 + About)
- research.html  研究 (3 个 panel + ADS Library)
- talks.html     报告与奖项
- outreach.html  科普与照片
- more.html      更多链接
- assets/style.css  样式 (颜色在文件最上面的变量里)
- assets/site.js    暗色模式按钮、首页大图加载

## 需要你放的图片 (放进 images/)
- hero.jpg              首页大图
- research_hifast.jpg   研究 panel: HiFAST
- research_hd2.jpg      研究 panel: HD2
- research_m31.jpg      研究 panel: M31

## 本地预览
双击 index.html, 或在本文件夹运行: python3 -m http.server 8000 然后打开 http://localhost:8000

最早的版本参考了 https://github.com/RayeRen/acad-homepage.github.io，Claude进行了大幅修改，十分感谢。
